# I.T.S.S. Thermal SCADA 애드온 사용 설명서

## 설치 및 접속
1. Home Assistant **설정 > 애드온 > 애드온 스토어 > 저장소**에 `https://github.com/morndew94/itss-ha`를 추가합니다.
2. **I.T.S.S. Thermal SCADA** 애드온을 설치하고 **사이드바에 표시**를 켠 뒤 시작합니다.
3. 좌측 사이드바의 **I.T.S.S. SCADA** 메뉴를 클릭하면 전용 웹 대시보드가 열립니다(HA Ingress 지원).

## 주요 기능
- **방별 설정온도 조절**: 웹 UI에서 각 방의 목표 온도를 `0.1°C` 단위로 실시간 설정 및 저장.
- **수동 운전 모드 (`AUTO` / `MANUAL`)**: 방별로 자동 제어와 수동 운전(강제 ON / 강제 OFF)을 즉시 전환 (`P000` 수동 우선 규칙 준수).
- **하이브리드 다중 방 제어**: 단일 바닥 온도 센서 공유 + 방별 개별 밸브 제어(동시 기동 + 개별 선차단).
- **시험 운전(Dry-Run) 토글**: 실제 보일러 제어 전 KST 이력과 예측 동작을 안전하게 검증.
- **Google API 보조 연동**: Gemini 검색 그라운딩 외기 보정, 일일 진단 리포트, 긴급 TTS 경보.
